Transitioning legacy GIS datasets from local desktop environments to modern web applications requires a robust spatial database and layer server.

## Setting Up PostGIS

PostGIS extends PostgreSQL with spatial data types, indexes, and queries. Storing geometries in PostGIS enables spatial SQL calculations directly within the database layer.

```sql
SELECT name, ST_Buffer(geom, 1000) AS buffer_zone
FROM municipal_assets
WHERE ST_DWithin(geom, ST_MakePoint(73.02, 33.68)::geography, 5000);
```
